# DPT Technology Solutions Hub

A responsive, interactive DPT Technologies enterprise technology portfolio/demo hub.

## Updated experience
- Opens directly on the Explore Services dashboard — no login/front page.
- Light enterprise base with multiple accent families: indigo, violet, cyan, orange and pink.
- Image-led "What we build" service cards with local visual assets.
- Website Development section now uses large visual website mockup images for Corporate Website, Business Portal and E-commerce Platform.
- Fully clickable navigation and demo interactions retained.
- All metrics and records are illustrative/demo data.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
The project includes `vercel.json` and is ready to deploy to Vercel.
